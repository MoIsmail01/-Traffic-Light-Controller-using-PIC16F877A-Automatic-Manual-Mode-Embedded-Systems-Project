I present a Traffic Light Controller project based on the PIC16F877A Microcontroller.

The system controls two roads and supports two operating modes:

🔹 Automatic Mode
🔹 Manual Mode

The project uses a Finite State Machine (FSM) to control the traffic light sequence, while Timer0 and Interrupts are used for timing.

The system also uses Seven-Segment Displays to show the Remaining Time for each road.

### ⚙️ Main Features

• PIC16F877A Microcontroller
• Automatic Traffic Light Control
• Manual Control Mode
• Finite State Machine (FSM)
• Timer0 & Interrupts
• Seven-Segment Displays
• 7447 BCD to Seven-Segment Decoder
• Countdown Timer
• Two-Road Traffic Control

### ⏱️ Timing

West Green: 20 seconds
West Yellow: 3 seconds
South Green: 12 seconds
South Yellow: 3 seconds

The project demonstrates how Hardware and Embedded Software can work together to implement a real-time Traffic Control System.
